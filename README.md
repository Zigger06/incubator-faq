# Мағозаи инкубаторҳо — FAQ

Саҳифаи расмии саволу ҷавоб барои муштариёни Мағозаи инкубаторҳо дар Тоҷикистон.

## Илова кардани саволи нав

Ҳамаи саволҳо дар файли `data/faqs.js` нигоҳ дошта мешаванд. Барои илова кардани савол, як объекти навро ба рӯйхати `FAQ_ITEMS` гузоред:

```js
{
  id: "unique-latin-id",
  category: "purchase",
  question: "Савол дар ин ҷо",
  answer: ["Ҷавоби асосӣ.", "Шарҳи иловагӣ."],
  keywords: ["калима", "барои", "ҷустуҷӯ"]
}
```

Категорияҳои дастрас: `purchase`, `models`, `setup`, `support`.

## Сохтор

- `index.html` — сохтори саҳифа
- `data/faqs.js` — маълумоти мағоза, категорияҳо ва саволҳо
- `assets/app.js` — ҷустуҷӯ, филтр ва кушодани ҷавобҳо
- `assets/styles.css` — намуди зоҳирӣ ва мутобиқшавӣ ба телефон

Саҳифа бе китобхонаҳои беруна кор мекунад ва барои GitHub Pages омода аст.
